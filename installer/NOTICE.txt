Zadoo Security Notice

Zadoo lets a person with a valid access code and share link view this Windows PC and, depending on the permissions you enable, control mouse, keyboard, clipboard, audio, microphone, camera, terminal, snapshots, tunnel refresh, and remote alerts.

Only install and run Zadoo on computers you own or are authorized to manage. Keep your access code and share links private. Stop Zadoo or refresh its public link when an old link should no longer work.
