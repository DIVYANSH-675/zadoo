Your PC. Your permissions.

Zadoo lets someone with your connection link and valid access code view this Windows PC. Only install it on a computer you own or are authorized to manage.

1. KEEP YOUR CODE PRIVATE
Share your access code and connection link only with people you trust. Do not post them publicly.

2. CHOOSE WHAT VIEWERS CAN DO
In Settings > Permissions, allow only the controls you need. Permissions cover the mouse, keyboard, clipboard, computer audio, microphone, camera, terminal commands, snapshots, video controls, link refresh and alerts. Terminal access can run commands on this PC.

3. STOP SHARING WHEN YOU ARE DONE
Select Stop in Settings to stop Zadoo. Refresh creates a new public link. You can change startup behavior in Preferences.

EVERY FEATURE IS FREE
No subscription or payment is required. The optional Support section shows the developer's QR code; contributing does not unlock features or change access.
